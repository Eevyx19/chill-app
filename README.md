Ini merupakan Tugas mission frontend intermediate 1B
Pada tugas ini terdapat 3 halaman yaitu halaman login, register dan main
Untuk mengakses halaman login dan register, cukup masukan "/login" untuk ke halmanan login dan "/register" untuk masuk ke halaman register di bagian akhir URL website
Dan untuk halaman utamanya cukup tekan link yang tersedia
